# Innovation write-ups

One file per idea tried in an innovation Sprint (see [process](../process.md#innovation-sprints)), named `sprint-NN-<slug>.md`, with four sections: **Question**, **What we tried**, **Evidence**, **Recommendation** (keep or drop, and why).

## Seed ideas

Ideas Developers or the PO can pitch at the first innovation Sprint's Planning. Anyone may add one.

| Idea | Why it might matter | Source |
|---|---|---|
